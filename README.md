# Deployment Bags
<!-- markdownlint-disable-next-line MD036 -->
**Portable networking labs · IT1080C · University of Cincinnati**

[![Open Issues](https://img.shields.io/github/issues/tyler-dalton/deployment-bags?style=flat-square)](https://github.com/tyler-dalton/deployment-bags/issues)

A modular, isolated networking lab initiative designed to bridge the gap between network theory and hands-on implementation. Deployment Bags provide reusable environments for students to configure, observe, and troubleshoot real networking equipment without relying on university production infrastructure.

The project prioritizes **flexibility, repeatability, and practical learning** over any single hardware configuration or network topology.

## Repository layout

- `docs/labs/` — current lab guides, setup procedures, and lab media
- `docs/operations/` — deployment and equipment-reset procedures
- `docs/infrastructure/` — supporting infrastructure documentation
- `docs/project/` — project goals, constraints, summaries, and action items
- `docs/reference/` — inventories and other reusable reference data
- `configs/` — device configurations organized by lab and platform
- `archive/` — lab versions that are no longer in use
